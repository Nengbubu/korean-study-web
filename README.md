# 韩语学习与点读

在线学习入口：https://nengbubu.github.io/korean-study-web/

包含 3–6 级共 253 篇对话、文章与补充阅读，支持文章侧边栏、搜索、逐句点读、男女声切换、倍速、单句循环、翻译拆解、重点词汇与语法查询。

## 手机使用

用 iPhone Safari 或 Android 浏览器打开在线入口即可学习。iPhone 可通过“分享 → 添加到主屏幕”保存入口。首次播放需加载所选文章的音频，建议在稳定网络下使用。

## 公开范围

此仓库和网页公开，任何人均可访问网页和音频。PDF 学习册与语法汇编保留在原私有仓库，不在此处发布。搜索引擎排除设置不构成访问限制。本站未安装访客追踪，无法识别或列出所有访问者。

## 停用

在仓库 Settings → Pages 中关闭发布或使用 Unpublish site。若也要停止公开仓库文件，须另行将仓库改为私有。已被下载的资料无法由停用操作撤回。

## 背诵练习

打开文章后选择“背诵练习”。支持中文提示揭晓、遮词背诵、逐句跟读和分段背诵；跟读句后自动留白，可调语速和停顿。难句标记仅在当前页面临时保留，刷新后清空。不记录背诵进度。
